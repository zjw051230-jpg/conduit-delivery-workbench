# Reference Notes

Map frontend surfaces by behavior:

- Home page: global feed, personal feed, article list, tag filter, Popular Tags sidebar.
- Article detail: article content, author/favorite/follow controls, comments.
- Editor page: create/update article form, title, description, body, tags.
- Profile page: profile header, follow action, authored/favorited articles, tabs or sections.
- Settings page: current user profile/account form.
- Popular Tags: sidebar or block that displays tag data and tag selection.

Candidate names are not guaranteed file names. Verify all route and component paths in `TARGET_REPO_PATH`.
