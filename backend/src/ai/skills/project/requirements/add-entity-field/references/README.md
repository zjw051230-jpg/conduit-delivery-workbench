# Reference Notes

Cross-stack field checklist:

- Model/schema or persistence representation.
- API create payload.
- API update payload.
- API read response and serializer/DTO.
- Frontend API client and data type.
- Editor form state, input, validation, and submit payload.
- Article list/card display.
- Article detail display.
- Profile-owned or favorited article display if the field appears there.
- Backend and frontend targeted tests.

Do not assume a database, ORM, or migration path exists. Verify the actual target repository structure first.
