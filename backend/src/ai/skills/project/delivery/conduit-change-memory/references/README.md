# Reference Notes

This directory stores file-based project memory for Conduit delivery runs.

- Read `memory-model.md` for classification and write rules.
- Append run history to `change-journal.md`.
- Store durable, evidence-linked facts in `project-facts.md`.
- Store proposed updates for other Skills in `skill-impact-index.md`.
- Store detailed per-run evidence under `rollout-summaries/`.

Do not treat these files as stronger than the current `TARGET_REPO_PATH` repository state. Stored memory is guidance that must be reverified before patching.
