# Skill Impact Index

Record proposed updates to existing Skills when delivery runs reveal stale, vague, or missing guidance. Suggestions are not applied automatically.

## Impact Template

```md
### <impactId>

- Status: proposed | accepted | rejected | applied
- Priority: low | medium | high
- Source Change: <changeId>
- Skill: <skillId>
- Impact Type: search-hint | clarification-rule | forbidden-change | test-rule | reference-note
- Reason: <why this Skill may need maintenance>
- Suggested Update: <specific suggested change>
- Applied In: <changeId or none>
```
