# Change Journal

Append one concise entry after each Conduit delivery run. Entries are historical evidence, not binding rules.

## Entry Template

```md
### <changeId>

- Date: <YYYY-MM-DD>
- Outcome: success | partial | failed | blocked
- Task: <short task summary>
- Matched Skills: <skill ids>
- Changed Files: <relative files from TARGET_REPO_PATH or none>
- Tests: <commands and status>
- PR Draft: <title or summary>
- Memory Notes: <semantic / episodic / procedural notes>
- Rollout Summary: references/rollout-summaries/<changeId>.md
```
