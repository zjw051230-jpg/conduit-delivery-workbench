# Reference Notes

Failure categories:

- `lint`: lint, format, unused variable, style, static analysis.
- `import`: unresolved module, missing export, wrong relative path.
- `undefined`: variable, property, function, or type is not defined.
- `test-failure`: assertion mismatch, snapshot mismatch, behavior failure.
- `command-missing`: script or executable does not exist.
- `dependency-missing`: dependency install or package resolution problem.
- `unknown`: evidence is incomplete.

PR Draft must include summary, changed files, tests run, known failures, and risk notes.
